    Instruction set
    
Eight 16-bit registers, 65,536 words of memory. The screen is memory-mapped at 0xF000: word 0xF000 + y*64 + x holds a colour 0–15. The stack grows down from 0xEFFF. Each instruction is one word — 6-bit opcode, three 3-bit register fields — plus one word when it carries an immediate. Labels end in :, constants are NAME = value, numbers can be decimal, 0x hex or 0b binary, and a+b works anywhere a value does.
